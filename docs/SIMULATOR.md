# GoldRush 2.0 模拟器使用指南

## 编译

```bash
cd game/
make sim          # 编译模拟器
make clean        # 清理
```

生成可执行文件 `sim`。

---

## 快速上手

### 1. 完整对战（默认随机策略，500轮）

```bash
./sim
```

输出：回放摘要 + 每轮金币统计 + CSV 文件

### 2. 策略对比

```bash
./sim --compare
```

输出：随机策略 vs 贪心策略 的金币对比 + 各自 CSV 文件

### 3. 交互式可视化演示

```bash
./sim --demo
```

每轮展示**真实地图** + **迷雾视图**，按 Enter 继续。

---

## 命令行参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--seed N` | 42 | 随机种子，控制地图生成 |
| `--rounds N` | 500 | 对战回合数 |
| `--compare` | off | 开启策略对比模式 |
| `--demo` | off | 开启逐步可视化 |

### 组合示例

```bash
./sim --seed 123 --rounds 200          # 自定义种子和轮数
./sim --compare --seed 99 --rounds 300 # 对比+自定义
./sim --demo --seed 1                  # 演示+指定种子
```

## CSV 导出

### 文件名规则

| 运行方式 | 文件名 |
|----------|--------|
| `./sim` | `replay_seed{N}_r{M}.csv` |
| `./sim --compare` | `replay_{策略名}_seed{N}.csv` |

### 列定义

| 列名 | 说明 |
|------|------|
| `round` | 回合数（0 开始） |
| `p1_gold_this` | 角色0本回合捡到金 |
| `p2_gold_this` | 角色1本回合捡到金 |
| `p1_cum` | 角色0累计持有金 |
| `p2_cum` | 角色1累计持有金 |
| `total_cum` | 两人合计累计金 |
| `p1_pos_r`, `p1_pos_c` | 角色0回合结束位置 |
| `p2_pos_r`, `p2_pos_c` | 角色1回合结束位置 |
| `p1_bombs` | 角色0本回合踩炸弹数 |
| `p2_bombs` | 角色1本回合踩炸弹数 |
| `enemy_cum` | 对手累计金 |
| `gold_on_map` | 地图剩余金 |
| `k` | 步数分割点 |
| `order` | 执行顺序（0=角色0先，1=角色1先） |
| `vp` | 视野购买（0=不买，1=7x7，2=9x9） |
| `p1_steps`, `p2_steps` | 各角色本回合实际步数 |
| `p1_collisions`, `p2_collisions` | 碰撞次数 |
| `vision_cost` | 本回合视野费用 |
| `cum_vision_cost` | 累计视野费用 |

## 当前策略

### 随机策略（baseline）

每步随机选择 0~4（上/下/左/右/不动），固定 k=4。

### 贪心策略

每轮向最近的**可见金子**移动，k=3（两角色各走3步）。

## 配置参数

所有参数在 `simulator.h` 的 `MapConfig` 结构体中定义：

```cpp
struct MapConfig {
    int    seed = 42;              // 随机种子
    double gold_density = 0.12;    // 初始金子密度
    double bomb_density = 0.05;    // 炸弹密度
    double obstacle_density = 0.08;// 障碍密度
    int    gold_spawn_per_round = 3; // 每轮新生成金子数
    int    gold_max_value = 5;    // 单格最大金子
    int    gold_min_value = 1;    // 单格最小金子
    int    npc_count = 5;         // NPC数量
    int    fog_radius = 5;        // 初始视野半径(方形，半径5=11x11)
    int    vp_cost_7x7 = 1;       // 购买7x7视野费用(金/回合)
    int    vp_cost_9x9 = 2;       // 购买9x9视野费用(金/回合)
    int    vision_7x7_radius = 3; // 7x7视野 = 半径3 (2*3+1=7)
    int    vision_9x9_radius = 4; // 9x9视野 = 半径4 (2*4+1=9)
};
```

### 视野系统

| vp值 | 视野大小 | 费用 | 说明 |
|------|---------|------|------|
| 0 | 基础视野(11×11) | 0 | fog_radius=5 |
| 1 | 7×7 | 1金/回合 | vision_7x7_radius=3 |
| 2 | 9×9 | 2金/回合 | vision_9x9_radius=4 |

> 注意：vp=1/2 视野比基础视野**更小**，但实际比赛中可能有其他机制（如穿透迷雾）。当前模拟器中购买视野是"缩小但可能更清晰"的效果，后续可根据真实规则调整。

## 规则假设

模拟器基于以下假设实现，可能与真实比赛规则有差异：

| 规则 | 当前假设 |
|------|----------|
| 角色初始位置 | 对角 (0,17) 和 (17,0) |
| 对手初始位置 | 左上角 (0,0) 和 (0,1) |
| 金子生成 | 每轮随机生成 3 个，值 1~5 |
| 炸弹效果 | 踩到损失 2 金，炸弹消失 |
| 迷雾 | 方形视野，初始半径5(11×11) |
| 视野购买 | vp=1: 7×7/1金; vp=2: 9×9/2金 |
| NPC | 随机游走，70%保持方向 |
| 对手 | 每角色每轮随机走 3 步 |
| 碰撞 | 两角色走到同一格，后到的停下 |
| 快照 | 每 10 轮一次 |
| 障碍 | -1 格子不可通过 |
| **连通性** | **BFS检测+自动修复，确保所有非障碍格子可达** |

## 如何添加自己的策略

在 `main_sim.cpp` 中定义一个符合 `GameOutput(*)(const GameInput*)` 签名的函数：

```cpp
extern "C" GameOutput myStrategy(const GameInput* input) {
    GameOutput out = {};
    // 你的策略逻辑
    out.k = 3;
    out.order = 0;
    out.vp = 0;
    for (int i = 0; i < S; i++) {
        out.actions[i] = /* 你的动作 */;
    }
    return out;
}
```

然后在 `main()` 中调用：

```cpp
testStrategy("我的策略", myStrategy, seed);
```
