# GoldRush 2.0 因子策略文档

## 因子列表

### F1: 淘金收益 (Gold Gain)
- **含义**: 模拟执行6步后捡到的金子总数
- **计算**: `sim0.gold_collected + sim1.gold_collected`
- **方向**: 越高越好
- **IC**: 1.0（目标变量，完美相关）
- **量化类比**: 股票的实际收益率

### F2: 避雷风险 (Bomb Risk)
- **含义**: 6步中踩到的炸弹次数
- **计算**: `sim0.bombs_hit + sim1.bombs_hit`
- **方向**: 越低越好（负向因子）
- **IC**: -0.34（强有效）
- **量化类比**: 下行风险/波动率

### F3: 探索覆盖 (Exploration)
- **含义**: 6步走过的不同格子总数
- **计算**: `sim0.unique_cells + sim1.unique_cells`
- **方向**: 越高越好
- **IC**: 0.10（弱有效）
- **量化类比**: 信息获取/调研深度

### F4: 敌人距离 (Enemy Proximity)
- **含义**: 执行前后与最近敌人的距离变化
- **计算**: `(dist_after - dist_before) × 2`（两个角色）
- **方向**: 正值=远离敌人，负值=靠近敌人
- **IC**: +0.48（强有效，正值说明地上金多时收益高）
- **量化类比**: 竞争强度/市场份额

### F5: NPC 遭遇 (NPC Encounter)
- **含义**: 结束位置附近(距离≤2)的NPC数量
- **计算**: `isNearNPC(end0) + isNearNPC(end1)`
- **方向**: 取决于NPC是否有奖励
- **IC**: 待测定
- **量化类比**: 事件驱动/催化剂

### F6: 路径效率 (Path Efficiency)
- **含义**: 实际移动步数 / 6（不动=浪费）
- **计算**: `(sim0.actual_moves + sim1.actual_moves) / 6.0`
- **方向**: 越高越好
- **IC**: -0.34（在随机策略中为负，因为"不动"反而避开了炸弹）
- **量化类比**: 资金使用效率/换手率

### F7: 碰撞次数 (Collisions)
- **含义**: 两个角色走到同一格的次数
- **计算**: 路径模拟中碰撞计数
- **方向**: 越低越好（负向因子）
- **IC**: -0.35（强有效，碰撞=浪费步）
- **量化类比**: 交易摩擦/滑点

### F8: 金币差距 (Deficit Factor)
- **含义**: 根据当前金币差距调整策略倾向
- **计算**: `-(my_gold - enemy_gold) / 10.0`
- **方向**: 正=落后（鼓励激进），负=领先（鼓励保守）
- **IC**: -0.01（噪音，待更多数据验证）
- **量化类比**: 相对收益/基准偏离

### F9: 中心靠近 (Center Proximity)
- **含义**: 结束位置到地图中心(8,8)的曼哈顿距离
- **计算**: `-(|row-8| + |col-8|) × 2`（两个角色合计）
- **方向**: 越高越好（负距离取反）
- **IC**: 0.55（强有效，仅次于F1）
- **量化类比**: 区位溢价/核心资产暴露

## 候选路径生成

当前实现使用**启发式候选**而非随机采样：

| 候选名 | 动作逻辑 | k | order | vp | 适用场景 |
|--------|---------|---|-------|----|---------|
| 贪心淘金 | 向最近金子直线移动 | 3 | 0 | 快照时买 | 默认 |
| 避雷淘金 | 向最近金子移动，绕开炸弹 | 3 | 0 | 快照时买 | 炸弹密集 |
| 抢金模式 | 靠近可见敌人方向 | 4 | 0 | 快照时买 | 敌人附近有金 |
| 中心集结 | 向中心9×9区域移动 | 3 | 0 | 不买 | 外围金子少 |
| 保守模式 | 原地不动 | 0 | 0 | 不买 | 大幅领先 |
| 激进模式 | 角色0走6步，角色1不动 | 6 | 0 | 买9×9 | 大幅落后 |

每轮对6个候选分别评分，选 Score 最高的返回。
